# Регулировка громкости сигналов в приложении

На экране настроек есть своя регулировка громкости сигналов. Она меняет только сигналы приложения и не трогает системную громкость. Диапазон 10–100% с шагом 5%, значение по умолчанию 100%, то есть как сейчас. Реализовано по плану `docs/plans/completed/20261102-signal-volume.md`.

Сигналы переходят с канала будильника (`USAGE_ALARM`) на канал навигации (`USAGE_ASSISTANCE_NAVIGATION_GUIDANCE`): звучат вместе с музыкой, приглушают её на время сигнала и регулируются обычными кнопками громкости. На большинстве телефонов этот канал следует громкости медиа. Точное поведение нужно проверить на телефоне.

`AudioTrack.setVolume()` только ослабляет звук, поэтому итоговая громкость равна настройке приложения, умноженной на системную громкость канала. Регулировка не сделает сигнал громче системного уровня, а при нулевой громкости медиа сигнала не будет.

Решения по тишине:
- нижний предел настройки 10%, а не 0%: состояния «тишина по настройке» нет, поэтому US-5 и US-6 нельзя нарушить случайно. Прижатие к диапазону выполняется и при чтении, и при записи;
- при нулевой громкости медиа тренировка запускается, а экраны отсчёта и тренировки показывают предупреждение. Громкость проверяется на каждом шаге, поэтому предупреждение исчезает, как только звук прибавят.
