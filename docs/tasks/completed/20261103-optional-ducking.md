# Отключаемое приглушение музыки перед сигналом

Сейчас сервис всегда приглушает музыку за `DUCK_AHEAD_MS` (1 с) до каждого сигнала: перед сменой отрезка, перед финалом и в конце отсчёта перед стартом. Не всем это нужно: на коротких отрезках музыка почти всё время тише, а приложения, которые на запрос фокуса ставят музыку на паузу, молчат ещё и секунду до сигнала. Приглушение заранее нужно сделать настройкой.

- На экране настроек появляется переключатель «Приглушать музыку заранее», по умолчанию включён: так приложение работает сейчас.
- Выключенный переключатель отключает только приглушение заранее. Сигнал по-прежнему берёт аудиофокус в момент звучания и приглушает музыку на время сигнала.
- Это настройка приложения, поэтому по правилу из `CLAUDE.md` она хранится отдельным ключом в `SettingsStore`, а не в `WorkoutSettings` и не в интенте. Сервис читает её в `startWorkout`, как вибрацию.
- Без приглушения заранее звук начнётся, пока система ещё плавно снижает громкость музыки, и первые доли секунды сигнала будут звучать на фоне почти полной громкости. Возвращать тишину перед звуком не нужно: она задержала бы сигнал относительно смены отрезка. Это ограничение надо описать в `README.md`, в «Известных ограничениях».
- Переключатель действует со следующей тренировки, идущая тренировка его не видит.

Решение о том, приглушать ли сейчас, остаётся в чистой функции: `shouldDuck` получает признак настройки параметром, сервис только передаёт его. Код с Android API не усложняется.
