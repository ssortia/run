# Выбор тренировки из готовой программы по неделям

На форме тренировки можно одним нажатием подставить время бега, время ходьбы и число повторов из готовой программы. Программа взята из таблицы в `plan.md` в корне проекта (после задачи файл удалён, программа живёт в `WorkoutPreset.kt`):

| Неделя | Интервал бега | Интервал ходьбы | Повторения |
| ------ | ------------- | --------------- | ---------- |
| 1      | 1 мин         | 2 мин           | 7          |
| 2      | 2 мин         | 2 мин           | 7          |
| 3      | 3 мин         | 2 мин           | 5          |
| 4      | 4 мин         | 2 мин           | 4          |
| 5      | 6 мин         | 2 мин           | 3          |
| 6      | 8 мин         | 90 сек          | 3          |
| 7      | 9 мин         | 90 сек          | 2          |
| 8      | 11 мин        | 90 сек          | 2          |
| 9      | 13 мин        | 1 мин           | 2          |
| 10     | 15 мин        | 1 мин           | 2          |
| 11     | 30 мин        |                 | 1          |

- Над полями формы появляется строка выбора недели с горизонтальной прокруткой: чипов 11, на узкий экран они не помещаются. Нажатие на чип заполняет поля бега, ходьбы и повторов. Значения в секундах раскладываются по полям минут и секунд: 90 сек это 1 мин 30 сек.
- Выбор только подставляет значения в поля. Их можно поправить вручную, сохраняются и проверяются они как обычно: через `WorkoutSettings.validate()` и `SettingsStore.save()` при старте. Отдельного ключа под выбранную неделю нет.
- Чип подсвечивается, если текущие значения полей совпадают с неделей программы. После ручной правки подсветка пропадает, после перезапуска вычисляется заново по сохранённым значениям.
- Итоговая длительность на форме пересчитывается сразу после выбора, как при вводе вручную.
- Таблица программы живёт в чистом коде без Android API (`WorkoutPreset.kt`): список недель с номером и значениями `WorkoutSettings`, функция поиска недели по настройкам. Подпись чипа собирается из строки ресурса с номером недели, переданной параметром.
- Значения по умолчанию в `WorkoutSettings` (2 / 2 / 7) совпадают с неделей 2, поэтому при первом запуске подсвечена она. Менять их не нужно.
- Неделя 11 (30 мин бега, 1 повтор) не имеет ходьбы, а `validate()` до этой задачи отклонял нулевую ходьбу (`SettingsError.WALK_ZERO`). После задачи `docs/tasks/completed/20261101-remove-last-walk.md` при одном повторе ходьба не звучит вовсе, поэтому правило надо ослабить: нулевая ходьба допустима при одном повторе. Это меняет US-2 и тесты `WorkoutSettings`. Неделя 11 подставляет ходьбу 0:00.
- После переноса таблицы в код `plan.md` удаляется, источником становится `WorkoutPreset.kt` и таблица в US-13 (`USER_STORIES.md`).
