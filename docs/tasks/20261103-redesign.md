# Новый дизайн: строгий и современный

Интерфейс собран из стандартных элементов Material 3 без общего стиля: текстовые кнопки «История», «Настройки» и «Назад», ряд чипов программы над полями, «Старт» посреди формы, история простым списком с разделителями. Нужен строгий современный вид и более удобная компоновка. Логика тренировки, сервис и хранение не меняются.

Макет: https://claude.ai/artifact/WKnsAn8dCvkNbCqtUVcdik (выбрана палитра «Изумруд»).

## Общий стиль

- **Цвет.** Нейтральный фон и один акцентный цвет. Оранжевый уходит, палитра «Изумруд»: белый текст на акценте и на экране бега в обеих темах. Карточки отличаются от фона только тоном, без теней и рамок. Тона `surfaceContainer*` задаются явно для светлой и тёмной схем: базовые значения Material 3 отдают фиолетовым и строгому виду не подходят.

  | Роль | Светлая | Тёмная |
  |---|---|---|
  | `primary` / `onPrimary` (Старт, переключатели, галочки) | `#047857` / `#FFFFFF` | `#047857` / `#FFFFFF` |
  | Бег: фон / текст | `#047857` / `#FFFFFF` | `#047857` / `#FFFFFF` |
  | Ходьба: фон / текст (прежние синие) | `#0B4F8A` / `#FFFFFF` | `#0F3556` / `#D6E8FF` |
  | Точка бега / ходьбы на форме | `#047857` / `#0B4F8A` | `#10B981` / `#4F8FCC` |
  | Фон / карточка / поле | `#F5F5F3` / `#FFFFFF` / `#F0F0EE` | `#111214` / `#1C1D20` / `#26272B` |
  | Текст / подписи / разделитель | `#16181B` / `#5C6066` / `#E4E4E1` | `#ECECEA` / `#A4A7AD` / `#2A2B2F` |
  | Ошибка | `#B3261E` | `#FFB4AB` |

  Точки на форме отделены от цвета фона отрезка: тёмный фон ходьбы на тёмной теме почти не виден, поэтому `SegmentColors` получает отдельный цвет метки или для точек заводится своя функция. Фон окна в `colors.xml` (`window_background_light`, `window_background_dark`) меняется на новый фон, иначе при запуске мелькнёт прежний. Бег и ходьба теперь с белым текстом, поэтому `darkStatusIcons` на тренировке вернёт светлые значки для обоих отрезков: тесты `ui/ThemeTest` под это обновляются.
- **Цифры.** Время и числа крупные, с моноширинными цифрами (`fontFeatureSettings = "tnum"`), чтобы значения не прыгали при смене. Стиль задаётся один раз в `ui/Theme.kt`. Подписи мелкие и приглушённые (`onSurfaceVariant`).
- **Иконки.** Material в стиле Outlined. Набор `material-icons-core` подключается явно в `app/build.gradle.kts` (версия из BOM): сейчас он приходит транзитивно через `material3`, а в `material3` 1.4 эту зависимость убрали. Иконки «История» в наборе нет, она добавляется векторным ресурсом `res/drawable/ic_history.xml` из Material Symbols (Apache 2.0). После смены зависимостей проверить версию `androidx.core`, как требует `CLAUDE.md`.
- **Верхняя панель.** На всех экранах вне тренировки `TopAppBar` из Material 3. У каждой иконки-кнопки есть `contentDescription`: прежние подписи «История», «Настройки», «Назад» остаются в `strings.xml` для TalkBack.

## Форма

```
┌──────────────────────────────────┐
│ RunTimer          [▦]  [◷]  [⚙]  │  программа, история, настройки
│ Неделя 2 программы               │  только если форма совпала с неделей
│ ┌──────────────────────────────┐ │
│ │ ● Бег               2:00   ⌄ │ │
│ └──────────────────────────────┘ │
│ ┌──────────────────────────────┐ │
│ │ ● Ходьба            2:00   ⌄ │ │
│ └──────────────────────────────┘ │
│ ┌──────────────────────────────┐ │
│ │ Повторы            −  [7]  + │ │
│ └──────────────────────────────┘ │
├──────────────────────────────────┤
│ ⚠ Система может остановить …  >  │  предупреждение о фоновой работе
│ Ходьба: от 1 секунды             │  только при ошибке
│ [            Старт             ] │
└──────────────────────────────────┘
```

1. **Верхняя панель.** Заголовок «RunTimer», справа иконки «Программа» (`Icons.Outlined.DateRange`), «История» и «Настройки» (`Icons.Outlined.Settings`). Кнопки «История» и «Настройки» под «Старт» удаляются.
2. **Программа в шторке.** Ряд чипов удаляется вместе с прокруткой к подсвеченному чипу (`BringIntoViewRequester`, флаг `scrolledToSelected`). Иконка «Программа» открывает `ModalBottomSheet` со списком недель. Строка недели: «Неделя 3», под ней «Бег 3:00 · Ходьба 2:00 · ×5» в формате минуты:секунды, как в истории, справа общее время («23 мин», «19 мин 30 с»). Общее время в строке остаётся: по нему недели удобно сравнивать. Оно всегда в одну строку и не сжимается (`maxLines = 1`, без `weight`), переносится при нехватке места строка параметров. Неделя, совпадающая с формой (`presetWeekOf`), отмечена галочкой. Нажатие заполняет форму, как раньше нажатие на чип, и закрывает шторку. Открытая шторка переживает поворот (флаг в `rememberSaveable`). Текст строки собирает чистая функция по образцу `runRowText`, подписи передаются параметрами.
3. **Признак недели.** Под заголовком подпись «Неделя N программы», если форма точно совпадает с неделей, иначе подписи нет.
4. **Выбор времени барабанами (вариант B в макете).** Бег и ходьба в карточках: цветная точка отрезка, подпись, время целиком («2:00») и шеврон. Нажатие раскрывает в карточке два вертикальных барабана, минуты 0…99 и секунды с шагом 5; раскрыта не больше одной карточки. Поля ввода минут и секунд с клавиатурой удаляются. Сохранённые секунды не на шаге 5 показываются как есть и не меняются, пока барабан не прокрутили. Проверка и сохранение прежние. Навигация остаётся иконками в верхней панели, вариант с нижней панелью вкладок отклонён.
5. **Повторы.** Степпер: «−», поле с числом посередине, «+». Поле остаётся редактируемым, чтобы 20 повторов не набирать нажатиями. Кнопки меняют число на 1 в пределах 1…`MAX_ROUNDS`, пустое или неверное поле кнопки считают как ближайшее допустимое значение. Логика шага живёт в чистой функции и покрыта тестами. Кнопка неактивна на границе диапазона.
6. **Общее время убирается.** Строки «Всего: …» на форме больше нет, строка `total_duration` удаляется. `formatTotal` остаётся: её используют история и шторка программы.
7. **Нижний блок закреплён.** Поля прокручиваются, а внизу всегда видны предупреждение о фоновой работе, ошибка формы и «Старт» на всю ширину. Ошибка показывается только когда она есть. Блок поднимается над клавиатурой (`safeDrawingPadding` у `NavHost` уже учитывает её). Пока клавиатура открыта, предупреждение о фоновой работе скрывается (`WindowInsets.isImeVisible`), иначе полям почти не остаётся места.
8. **Предупреждение о фоновой работе.** Компактный баннер-карточка: иконка `Warning`, текст и кнопка-стрелка, открывающая страницу приложения в системных настройках. Цвет не красный: старт предупреждение не блокирует.

## Настройки

- Слева в верхней панели стрелка «Назад» (`Icons.AutoMirrored.Outlined.ArrowBack`) и заголовок «Настройки». Текстовая кнопка «Назад» удаляется, колбэк прежний, через `dropUnlessResumed`.
- Пункты сгруппированы в карточки с заголовками: «Сигналы» (громкость, вибрация, приглушение музыки), «Тренировка» (задержка старта), «Оформление» (тема). Поведение пунктов не меняется.

## История

```
┌──────────────────────────────────┐
│ ←  История                       │
│ НОЯБРЬ 2026                      │
│ ┌──────────────────────────────┐ │
│ │  3   Бег 2:00 · Ходьба 2:00  │ │
│ │  пн  ×7 · 18:42       28:00 ✓│ │
│ │                           [🗑]│ │
│ └──────────────────────────────┘ │
└──────────────────────────────────┘
```

- Верхняя панель со стрелкой «Назад» и заголовком «История», текстовая кнопка «Назад» удаляется.
- Записи сгруппированы по месяцам старта, новые сверху, над группой заголовок месяца («ноябрь 2026», в интерфейсе прописными). Группировку делает чистая функция с зоной и локалью в параметрах. Месяц форматируется отдельным явным шаблоном с самостоятельной формой (`LLLL yyyy`), а не `ofLocalized…`, по той же причине, что дата строки (см. `CLAUDE.md`).
- Запись в карточке: слева крупно число и сокращённый день недели, в середине бег и ходьба отдельными строками в две колонки: подписи слева, время справа, выровнено друг под другом, без переноса; ходьба без времени не показывается и строка «×7 · 18:42» (повторы и время старта), справа длительность крупно и значок статуса: галочка для завершённой, квадрат «стоп» для остановленной, с `contentDescription` «завершена» или «остановлена». `RunRowText` и `runRowText` переделываются под эти поля, правила форматирования прежние (длительность вниз до секунды через `formatElapsed`).
- Удаление: иконка корзины в карточке, дальше прежний диалог подтверждения. `contentDescription` корзины по-прежнему называет дату записи.
- Пустая история: по центру иконка и текст «Пробежек пока нет». Пока база не ответила (`records == null`), экран пустой, как сейчас.
- Сводки над списком нет: статистика вне первой версии (`USER_STORIES.md`).
