# Прогресс лентой

Экран прогресса сейчас показывает итог «N из 10 недель пройдено», полосу из 10 делений и одну карточку со всеми неделями. Из него видно, что сделано, но не видно, где человек находится сейчас: какая неделя в работе и сколько до её конца. Экран переделывается в вертикальную ленту: недели идут сверху вниз, слева линия с узлом на каждую неделю, текущая неделя выделена отдельной карточкой с плашкой «Сейчас».

Макет: артборды «Прогресс лентой» и «Тёмная · прогресс лентой» в https://claude.ai/artifact/WKnsAn8dCvkNbCqtUVcdik. Из макета берутся раскладка, узлы ленты и карточки. Шрифты, отступы и цвета остаются из приложения: стили `MaterialTheme.typography`, `TabularNumbers`, `SectionCard`, цвета из `ui/Theme.kt`. Нижняя панель уже сделана, в задаче она не меняется. Дата в макете сокращённая («20 окт»), остаётся прежняя «20 октября» из `progressDateFormatter`: сокращённый месяц в `ru` пишется с точкой, и в JDK и на телефоне она может различаться.

## Экран

```
┌──────────────────────────────────┐
│ Прогресс                         │
│ ✓ ┌────────────────────────────┐ │
│ ┃ │ Неделя 1             5 раз │ │  пройдена: круг с галочкой
│ ┃ │ Бег 1:00 · Шаг 2:00 · ×7   │ │
│ ┃ │                 20 октября │ │
│ ┃ └────────────────────────────┘ │
│ – ┌────────────────────────────┐ │
│ ┃ │ Неделя 2            2 раза │ │  не закрыта до текущей: зелёный круг
│ ┃ └────────────────────────────┘ │  с прочерком, линия зелёная
│ ◕ ┌────────────────────────────┐ │
│ │ │ Неделя 3         [Сейчас]  │ │  текущая: кольцо из 4 частей
│ │ │ Бег 3:00 · Шаг 2:00 · ×5   │ │
│ │ │ ▬▬▬▬ ▬▬▬▬ ▬▬▬▬ ▭▭▭▭        │ │  4 деления
│ │ │ Пробежек 3 из 4   3 ноября │ │
│ │ └────────────────────────────┘ │
│ ○ ┌────────────────────────────┐ │
│ │ │ Неделя 4                 — │ │  впереди: полое кольцо
│ │ └────────────────────────────┘ │
│ …                                │
└──────────────────────────────────┘
```

- **Итога и полосы из 10 делений больше нет**, как в макете. Сразу под `AppTopBar` лента из всех 10 недель, каждая неделя своей карточкой (`surfaceContainer`), без разделителей.
- **Текущая неделя** («Сейчас») — неделя последней завершённой пробежки по программе (правило ниже). Её карточка крупнее: заголовок «Неделя N» и справа плашка «Сейчас» цветами `WeekChip` (`secondaryContainer` / `onSecondaryContainer`), параметры недели, полоса из 4 делений и строка «Пробежек N из 4» с датой последней пробежки справа. Делений всегда 4 (`RUNS_TO_PASS_WEEK`), даже если пробежек больше: закрашено `min(N, 4)`. Число при этом пишется настоящее: с 4 и больше вместо «Пробежек 5 из 4» строка «Неделя пройдена · 5 раз» (склонение из `progress_runs`). Без пробежек у текущей недели (только при пустой истории, см. ниже) даты нет.
- **Остальные недели** — компактная карточка: «Неделя N» и параметры слева, справа число пробежек («1 раз», «5 раз») и под ним дата последней. Без пробежек справа «—» цветом `onSurfaceVariant`, даты нет. Заголовок непройденных недель, кроме текущей, цветом `onSurfaceVariant`, пройденных и текущей — обычным.
- **Узлы ленты** стоят на уровне заголовка карточки:
  - пройденная неделя (4 и больше пробежек), где бы она ни стояла: закрашенный круг цветом `marker` с галочкой `progressCheckColor`, как сейчас;
  - текущая: кольцо из 4 частей (как нынешнее `WeekRing`, но крупнее, около 28 dp) с точкой `marker` в центре; у пройденной текущей все 4 части закрашены;
  - непройденная неделя **выше текущей**: круг размера круга с галочкой, залитый `marker`, как у пройденной, но с прочерком вместо галочки цветом `progressCheckColor`. Отличается от пройденной только значком. Пробежки у неё могут быть, справа в карточке тогда их число;
  - непройденная неделя **ниже текущей**: полое кольцо около 12 dp, обводка `marker`, если пробежки у недели есть, иначе `progressTrackColor`.
- **Линия** между узлами шириной 2 dp. Отрезок между неделями N и N+1 зелёный (`marker`), если неделя N выше текущей или пройдена, иначе `progressTrackColor`. Так вся линия до узла текущей недели зелёная, даже через незакрытые недели, а ниже текущей зелёные только отрезки под пройденными неделями. Над первой неделей и под последней линии нет. Узлы рисуются поверх линии с кольцом цвета фона, как `box-shadow` в макете, чтобы линия не просвечивала.
- **Пока поток записей не пришёл** (`null`), под шапкой ничего нет, как сейчас.
- Карточки не нажимаются. Прокрутка к текущей неделе при открытии не нужна: недель 10, текущая видна или в одном жесте.

## Правила

- **Текущая неделя.** Среди завершённых пробежек (`completed`), у которых `presetWeekOf(record)` не `null`, берётся пробежка с наибольшим `startedAtMs`, её неделя и есть текущая. Если последняя завершённая пробежка была с параметрами не из программы, она пропускается и берётся более ранняя, и так далее. Остановленные пробежки не учитываются, как и в подсчёте. При равном `startedAtMs` берётся большая неделя, чтобы результат не зависел от порядка списка. Если завершённых пробежек по программе нет совсем, текущей считается неделя 1: «Сейчас» есть всегда, и экран с пустой историей показывает, с чего начинать.
- **Текущая неделя может быть пройденной** (человек бежит её в пятый раз) и может стоять ниже пройденных или выше них: недели можно проходить не по порядку. Узел и карточка «Сейчас» у неё есть в любом случае.
- Подсчёт пробежек, порог 4, определение недели записи и то, что прогресс не хранится, а считается из истории, не меняются. Удаление записи в истории может сменить текущую неделю.

## Как сделать

1. **Логика** в `ProgramProgress.kt` без Android API. Текущая неделя и вид узла считаются там же, где `programProgress`, а не в Compose. Например:

   ```kotlin
   enum class WeekMark { PASSED, CURRENT, SKIPPED, AHEAD }

   data class WeekProgress(
       val preset: WorkoutPreset,
       val completedRuns: Int,
       val lastCompletedAtMs: Long?,
       val current: Boolean,
       /** Отрезок линии от этой недели к следующей закрашен. */
       val lineToNextFilled: Boolean,
   ) {
       val week: Int get() = preset.week
       val passed: Boolean get() = completedRuns >= RUNS_TO_PASS_WEEK
       val mark: WeekMark get() = when { current -> CURRENT; passed -> PASSED; … }
   }
   ```

   Форма данных на усмотрение, но правила текущей недели, вида узла и цвета отрезков должны быть в чистом коде и покрыты тестами.
2. **Текст** в `ProgressRowText.kt`: строка «Пробежек N из 4» или «Неделя пройдена · N раз» для текущей карточки, число и дата для остальных. Подписи («Сейчас», шаблоны) приходят параметрами, склонение из `<plurals>`. Ресурсы итога (`progress_summary`, `progress_summary_description`), которые станут не нужны, удалить.
3. **Экран** `ProgressContent.kt`: убрать `SummaryCard` и `WeeksCard`, собрать ленту. Колонку узлов и линию проще рисовать в каждой строке своей: `Row` с колонкой фиксированной ширины (около 28 dp) и карточкой, `IntrinsicSize.Min` или `drawBehind` для линии на всю высоту строки вместе с промежутком до следующей карточки, иначе между строками линия прервётся. Прокрутка по-прежнему `verticalScroll`, недель всего 10.
4. **Цвета.** Новых литералов в экране нет, все из `ui/Theme.kt`. Прочерк берёт `progressCheckColor`, его контраст на `marker` уже проверяет `ThemeTest`. Добавить в `ThemeTest` для обеих тем: линия `marker` на `background` не меньше 3:1 (линия несёт смысл, в отличие от фоновой дорожки).
5. **TalkBack.** Каждая неделя читается одной фразой, узел и линия скрыты. Текущая: «Неделя 3, сейчас, пробежек 3 из 4, последняя 3 ноября». Пройденная: «Неделя 1, пройдена, 5 раз, последняя 20 октября». Незакрытая выше текущей и впереди: «Неделя 2, пробежек 2 из 4, последняя …» или «Неделя 4, пробежек нет». Число в карточке, уже названное в описании, не читается второй раз (как `runsSpoken` сейчас). Полоса из 4 делений скрыта.

Схема базы, `RunRecord`, сервис, история и форма не меняются.
