## Solution Overview
- **Палитра и стиль в одном месте.** Цвета, тона карточек и стиль цифр живут в `ui/Theme.kt`, схема строится функцией `appColorScheme(darkTheme)` (internal), чтобы её можно было проверить тестом. Фон окна остаётся одним источником в `colors.xml`: `RunTimerTheme` по-прежнему подставляет его в `background` и `surface`. Экраны берут цвета из `MaterialTheme.colorScheme` и `segmentColors`, своих литералов цвета не заводят.
- **Общие элементы.** Новый файл `ui/Components.kt`: верхняя панель `AppTopBar` (заголовок, необязательная стрелка «Назад», действия), карточка `SectionCard` и заголовок группы `SectionTitle`. Своей обёртки для кнопки-иконки нет: хватает `IconButton` с `Icon(contentDescription = …)`.
- **Барабан времени.** Общий компонент `TimeWheel` в `ui/TimeWheel.kt` на `LazyColumn` со снаппингом. Какие значения в нём стоят и какое выбрано, решают чистые функции, Compose только прокручивает и рисует.
- **Чистая логика отдельно.** Текст строки недели и её общее время, шаг повторов, значения барабанов, группировка истории и поля карточки записи считаются чистыми функциями с подписями и форматами в параметрах, по образцу `runRowText`.
- **Навигация не меняется.** Маршруты, `dropUnlessResumed`, `screen()` с непрозрачным фоном и колбэки `WorkoutScreen` остаются. Шторка программы не маршрут, а состояние формы.

## Technical Details
- **Палитра** (светлая / тёмная):
  - `primary` / `onPrimary`: `#047857` / `#FFFFFF` в обеих темах.
  - Бег: фон `#047857`, текст `#FFFFFF` в обеих темах.
  - Ходьба остаётся прежней синей, как сейчас в приложении: светлая `#0B4F8A` / `#FFFFFF`, тёмная `#0F3556` / `#D6E8FF`.
  - Точки отрезка на форме, новое поле `marker` в `SegmentColors`: светлая `#047857` / `#0B4F8A`, тёмная `#10B981` / `#4F8FCC`.
  - Фон (`colors.xml`) / карточка (`surfaceContainer`) / поле (`surfaceContainerHigh`): `#F5F5F3` / `#FFFFFF` / `#F0F0EE` и `#111214` / `#1C1D20` / `#26272B`. `surfaceContainerLowest`, `Low`, `Highest`, `surfaceVariant`, `surfaceBright`, `surfaceDim` задаются нейтральными серыми.
  - Текст (`onSurface`, `onBackground`) / подписи (`onSurfaceVariant`) / разделитель (`outlineVariant`): `#16181B` / `#5C6066` / `#E4E4E1` и `#ECECEA` / `#A4A7AD` / `#2A2B2F`.
  - `outline` (рамки полей и обведённых кнопок): `#8A8D92` / `#6E7176`.
  - `surfaceTint` = `Color.Transparent`: иначе диалог удаления и шторка с `tonalElevation` подмешивают акцент к фону.
  - `secondaryContainer` / `onSecondaryContainer` (выбранные элементы, например строка недели): `#E3EFEA` / `#0B2B24` и `#1F3A33` / `#D1FAE5`. `inverseSurface` / `inverseOnSurface` нейтральные.
  - Ошибка: `#B3261E` / `#FFB4AB`.
  - ⚠️ Бег и ходьба теперь различаются оттенком (зелёный и синий), а не яркостью: контраст фонов 1,53:1 в светлой теме и 2,3:1 в тёмной, а `ThemeTest` требует ≥ 3:1. Цвета выбрал пользователь, поэтому тест «бег и ходьба различаются по яркости» заменяется тестом «бег и ходьба различаются оттенком»: разница тонов не меньше 60° в обеих темах (тон считается в тесте из RGB, у `Color` в Compose его нет). Комментарий в тесте объясняет замену: смену отрезка видно по оттенку и по надписи «Бег» / «Ходьба». Зелёный и синий различимы и при самой частой дальтонии (дейтеранопии), но слабее, чем прежние оранжевый и синий.
- **Стиль цифр.** Константа `TabularNumbers` в `ui/Theme.kt` с `fontFeatureSettings = "tnum"`, применяется через `style.merge(...)` к полям времени, повторам, длительностям, таймеру.
- **Строка недели** `presetRowText(preset, weekTitle: String, runLabel, walkLabel, minLabel, secLabel): PresetRowText(title, details, total)`:
  - `title` — готовая строка «Неделя 3» из `preset_week`.
  - `details` — «Бег 3:00 · Ходьба 2:00 · ×5», минуты:секунды через `formatTotal`, ходьба без времени не показывается. Неделя 11: «Бег 30:00 · ×1».
  - `total` — словами, как в задаче и макете: «23 мин», «19 мин 30 с». Отдельная чистая функция `formatPresetTotal(totalMs, minLabel, secLabel)`, подписи «мин» (новая строка) и «с» (`seconds_short`). Час и больше в программе не встречается, но функция пишет «60 мин» и больше без часов, это проверяется тестом. Общее время равно `settings.toWorkout().totalMs`: последняя ходьба не входит, неделя 3 = 23 мин.
- **Шаг повторов.** `stepRounds(text: String, delta: Int): String` сначала прижимает разобранное значение (`parseField`) к `1..MAX_ROUNDS`, потом прибавляет `delta` и прижимает снова, поэтому переполнения нет. `canDecreaseRounds(text)` и `canIncreaseRounds(text)` считают по тому же прижатому значению.

  | Поле | Действие | Результат |
  |---|---|---|
  | `"7"` | +1 / −1 | `"8"` / `"6"` |
  | `""` | +1 | `"2"` (пустое считается 1) |
  | `""` | −1 | кнопка неактивна, `"1"` |
  | `"1"` | −1 | кнопка неактивна, `"1"` |
  | `"99"` | +1 | кнопка неактивна, `"99"` |
  | `"150"` | −1 | `"98"` |
  | `"99999999999"` | −1 | `"98"` |
  | `"0"` | +1 | `"2"` (0 считается 1) |

- **История:**
  - `RunRowText` получает поля `day` («3»), `weekday` («вт»), `runTime` («2:00»), `walkTime` («2:00» или `null`, если ходьбы нет), `meta` («×7 · 18:42»). Подписи «Бег» и «Ходьба» в `RunRowText` не входят, экран берёт их из строк. Бег и ходьба стоят отдельными строками в две колонки: подписи слева, время справа, время выровнено по правому краю колонки и с `TabularNumbers`, чтобы «2:00» и «13:00» стояли друг под другом. В Compose это `Row` из двух `Column` (подписи, время с `horizontalAlignment = End`), текст без переноса (`maxLines = 1`, `softWrap = false`), `duration` (`formatElapsed`), `completed`, `date` (полная дата для диалога и описания корзины, как сейчас). `runRowText` принимает подписи «Бег» и «Ходьба», подписи статуса уходят из параметров: статус показывается значком, `history_completed` и `history_stopped` становятся его `contentDescription`.
  - Все форматы собираются в один объект `RunFormatters(date, day, weekday, time, month)`, создаётся функцией `runFormatters(zone, locale)` один раз на экран через `remember(zone, locale)`. Явные шаблоны: прежний `d MMMM yyyy, HH:mm`, день `d`, день недели `EEE`, время `HH:mm`, месяц `LLLL yyyy` (самостоятельная форма: «ноябрь 2026»).
  - `groupRunsByMonth(records, zone): List<RunMonth(yearMonth, records)>` группирует уже отсортированные записи (новые сверху) по `YearMonth` старта в переданной зоне, порядок групп и записей сохраняется. Заголовок группы форматирует `runMonthTitle(yearMonth, formatters)`.
  - ⚠️ `EEE` и `LLLL` в JDK берутся из CLDR, а на телефоне из ICU. Для русской локали ожидаются одинаковые «вт» и «ноябрь», но подтверждается это только на телефоне.
- **Выбор времени (вариант B):**
  - Карточка отрезка в свёрнутом виде: точка `marker`, подпись «Бег» или «Ходьба», время целиком («2:00», `formatTime`-формат «м:сс» из полей формы) крупно с `TabularNumbers` и стрелка-шеврон. Вся строка — кнопка с `Role.Button`, `stateDescription` «развёрнуто» / «свёрнуто».
  - Нажатие раскрывает под строкой два барабана, минуты и секунды, с подписями «мин» и «с» под ними. Видно три строки по 44 dp, выбранная в середине на подложке `surfaceContainerHigh`, соседние мельче и цветом `onSurfaceVariant`. Время в строке карточки окрашено `primary`, пока карточка раскрыта.
  - Раскрыта не больше одной карточки: открытие второй сворачивает первую. Повторное нажатие сворачивает. Какая раскрыта, хранит `rememberSaveable` формы (`null`, «бег», «ходьба»); по умолчанию обе свёрнуты.
  - Барабан — `LazyColumn` высотой три строки с `rememberSnapFlingBehavior` и отступами сверху и снизу на одну строку, чтобы крайние значения вставали в середину. Значение фиксируется, когда прокрутка остановилась (`snapshotFlow { isScrollInProgress }`), по индексу строки в середине. Нажатие на соседнее значение прокручивает к нему (`animateScrollToItem`). Барабан не закольцован.
  - Значения: минуты 0…`MAX_MINUTES` с шагом 1, секунды 0…55 с шагом 5. Чистая функция `wheelOptions(max, step, current)` возвращает список значений; если сохранённое значение не кратно шагу (например, 7 секунд из прежней версии), оно вставляется в список на своё место, чтобы открытие барабана молча не меняло настройку. `wheelIndexOf(options, value)` даёт индекс выбранного. Значения больше `max` (неверное сохранённое) прижимаются к `max` только для показа, правка и проверка формы прежние (`WorkoutSettings.validate()`).
  - Выбор записывается в те же строковые поля `SettingsInput` (`runMin`, `runSec`, `walkMin`, `walkSec`), поэтому проверка, сохранение, `presetWeekOf` и шторка программы не меняются. Поля ввода минут и секунд с клавиатурой удаляются; клавиатура остаётся только у поля повторов.
  - Доступность: у каждого барабана `contentDescription` («Бег, минуты»), у строк `Role.Button` и `selected`; TalkBack выбирает значение двойным нажатием на строку. Действия «увеличить» и «уменьшить» через `customActions` можно добавить позже, если перебирать строки окажется неудобно.
- **Форма:** `Column` с прокручиваемой областью `weight(1f)` и закреплённым нижним блоком. Предупреждение о фоновой работе скрыто при открытой клавиатуре (`WindowInsets.isImeVisible`, `@OptIn(ExperimentalLayoutApi::class)`). Кнопка-стрелка баннера получает `contentDescription` из `button_open_app_details`.
- **Шторка:** `ModalBottomSheet`, флаг `showProgram` в `rememberSaveable`. `onDismissRequest = { showProgram = false }`. Выбор недели вызывает прежний `onSelect`, затем `scope.launch { sheetState.hide() }.invokeOnCompletion { if (!sheetState.isVisible) showProgram = false }`, чтобы флаг не разошёлся с состоянием шторки.
- **Иконки:** `implementation("androidx.compose.material:material-icons-core")` без версии (из BOM). `res/drawable/ic_history.xml` из Material Symbols «history» (Outlined, 24 dp, Apache 2.0), подключается через `painterResource`.
- **Строки:** заголовок истории — «История»: значение `history_title` меняется. Новые: «Неделя %1$d программы», «мин», «Меньше повторов», «Больше повторов», заголовки групп настроек «Сигналы», «Тренировка», «Оформление», подписи «Громкость» и «Задержка старта» отдельно от значений. Удаляются ставшие ненужными (`total_duration` и прежние составные подписи ползунков, если они больше нигде не используются), чтобы lint не выдал `UnusedResources`.
