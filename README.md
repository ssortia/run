# RunTimer

Простой интервальный таймер для бега под Android. Чередует отрезки бега и шага, подаёт звуковой сигнал при каждой смене отрезка и другой сигнал в конце тренировки, сигналы дублируются вибрацией. Перед стартом можно задать задержку, её конец тоже слышно. Тренировку можно поставить на паузу, а её экран свернуть и во время бега открыть историю, прогресс или настройки. Каждая пробежка сохраняется на телефоне, список прошедших открывается вкладкой «История». Для программы из 10 недель есть экран прогресса: сколько раз пробежана каждая неделя, какие пройдены и какая сейчас в работе.

Пример: 2 минуты бега, 2 минуты шага, 7 повторов. В последнем повторе только бег, поэтому это 13 отрезков и 26 минут тренировки.

Сценарии использования описаны в [USER_STORIES.md](USER_STORIES.md).

Дизайн-макет экранов (палитра «Изумруд», нижняя навигация): [RunTimer — новый дизайн](https://claude.ai/artifact/WKnsAn8dCvkNbCqtUVcdik). Прототипы иконки приложения: [Иконка RunTimer](https://claude.ai/artifact/PBGGxgEGYZKHq1BBvPQRpx). Обе страницы приватные, открываются только у владельца или у тех, с кем ими поделились.

## Запуск на телефоне

```bash
./run-device.sh          # собрать, установить и открыть приложение
./run-device.sh --logs   # то же, затем показать логи (выход по Ctrl+C)
```

Телефон подключается по USB, на нём должна быть включена «Отладка по USB» и подтверждён запрос на отладку с этого компьютера. Если телефон не готов, скрипт сообщает об этом до сборки. К компьютеру должен быть подключён один телефон, эмулятор не мешает.

## Сборка

Нужны JDK 17 и Android SDK, путь к SDK задаётся в `local.properties` (`sdk.dir=…`).

```bash
./gradlew test assembleDebug   # тесты и debug-APK
./gradlew lintDebug            # lint
```

APK появится в `app/build/outputs/apk/debug/app-debug.apk`. CI на GitHub проверяет каждый push в `master` и каждый PR. Подробнее о сборке, эмуляторе, CI и установке APK: [docs/building.md](docs/building.md).

## Важно: фоновая работа

На realme, OPPO и OnePlus включите «О приложении → Использование батареи → Разрешить работу в фоновом режиме», на Xiaomi, Huawei, Samsung и других отключите для приложения экономию батареи. Без этого сигналы пропадают примерно через минуту после выключения экрана. Форма предупреждает об этом баннером. Это ограничение не то же самое, что завершение процесса прошивкой realme, OPPO и OnePlus через 5 минут после блокировки экрана: от него переключатель не спасает, его закрывает беззвучная дорожка, которую приложение проигрывает всю тренировку. Подробнее в [docs/limitations.md](docs/limitations.md).
